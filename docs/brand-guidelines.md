# Brand Guidelines (Draft)

## Brand Name
- Sales University

## Visual Style
- Dark, premium, “royal / elite” tone.
- Crest is the center brand asset.

## Colors (Initial)
- Background: near-black
- Text: white + muted gray
- Accent: gold (from crest)
- Secondary: deep blue (from crest shield) if needed sparingly

## Typography (Suggestion)
- Headings: modern sans, bold
- Body: modern sans, readable
(Exact font choice can be decided later; keep default Next font for now.)

## Imagery
- Static imagery only.
- Use the crest large in hero.
- Future: generated images via AI should match premium dark aesthetic.

## UI Motifs
- Subtle borders, soft glows, glassy panels (very controlled).
- Buttons: clean, slightly rounded, premium hover.
